## 📋 Тапсырма: Тіркелу формасы — Қысқаша түсіндірме

### 1. Қандай тексерулер (валидациялар) орындалды?
1. **Міндеттілік тексеруі (`required`):**  
   HTML5 деңгейінде әр өріске `required` атрибуты қойылды, ал JavaScript деңгейінде `input.value.trim() === ""` тексеріліп, бос таңбалардан тұратын жолдар жіберілмейді.
2. **Email пішімін тексеру (`type="email"`):**  
   HTML5 браузерлік валидациясынан бөлек, JavaScript-те тұрақты өрнек (RegEx: `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`) арқылы `@` және нүктенің дұрыс орналасуы тексеріледі.
3. **Құпиясөз ұзындығын тексеру (`minlength="8"`):**  
   Құпиясөзге кемінде 8 таңба енгізілуі тиіс. 8-ден аз болғанда қызыл түспен «Құпиясөз тым қысқа! Кемінде 8 таңба болуы шарт» деген ескерту шығады.
4. **`submit` оқиғасын өңдеу:**  
   `form.addEventListener("submit", (e) => {...})` көмегімен форманың жіберілуі қадағаланады. `e.preventDefault()` парақшаны қайта жүктелуден сақтайды.
5. **Сәтті хабарлама:**  
   Егер барлық 3 өріс тексеруден қатесіз өтсе, экранда жасыл түсті «Құттықтаймыз! Сіз сәтті тіркелдіңіз!» хабарламасы және пайдаланушы деректері көрсетіледі.

### 2. Сыналған қате жағдайлар (Кемінде 2 қате сценарийі):
- 🔴 **1-қате жағдай (Қысқа құпиясөз):** Пайдаланушы 8 таңбадан аз құпиясөз енгізді (мысалы, `"12345"`). Нәтижесі: Құпиясөз өрісі қызылмен белгіленіп, қате мәтіні шықты.
- 🔴 **2-қате жағдай (Қате Email форматы):** Пайдаланушы `@` белгісі жоқ мән енгізді (мысалы, `"anuar-mail-ru"`). Нәтижесі: Email өрісі қызылмен қоршалып, қате ескертуі көрсетілді.
- 🔴 **3-қате жағдай (Бос өріс):** Аты-жөні өрісі толтырылмады. Нәтижесі: «Аты-жөніңізді толық енгізіңіз» деген қате көрсетілді.
- 🟢 **Сәтті жағдай:** Барлық өрістер талапқа сай толтырылып, сәтті тіркелу хабарламасы шықты.

## 📝 Практикалық сабақ №10 — Бақылау сұрақтары мен жауаптары

1. **input тегінің type="date" және type="color" түрлері веб-бетте қандай интерфейс элементтерін көрсетеді?**  
   *Жауабы:* `type="date"` күнтізбе виджетін (Date picker) көрсетеді, пайдаланушы күн/ай/жылды таңдайды (`YYYY-MM-DD`). `type="color"` түстер палитрасын (Color picker) ашатын батырманы көрсетеді және түстің HEX кодын (мысалы `#ff0000`) қайтарады.

2. **JavaScript арқылы енгізу өрісіндегі мәнді алу үшін қандай қасиет (property) қолданылады?**  
   *Жауабы:* `.value` қасиеті қолданылады (мысалы, `document.getElementById("id").value`).

3. **innerHTML қасиетінің textContent қасиетінен басты айырмашылығы неде?**  
   *Жауабы:* `innerHTML` HTML тегтерін оқиды және өңдеп, DOM құрылымын визуализациялайды. `textContent` кез келген мазмұнды таза мәтін (raw text) ретінде қабылдап, тегтерді орындамай жай мәтін күйінде шығарады.

4. **Шартты операторлар (if...else) бұл тапсырмада не үшін қажет болды?**  
   *Жауабы:* Ойыншы енгізген санды компьютердің жасырын санымен салыстырып, үш бағыт бойынша әрекет ету үшін: 1) дұрыс болса — жеңіс; 2) кіші болса — «Сан үлкенірек»; 3) үлкен болса — «Сан кішірек».

5. **Нәтиженің шекара түсін динамикалық түрде өзгерту (resultBox.style.borderColor = selectedColor) DOM бағдарламалауында қандай деңгейге жатады?**  
   *Жауабы:* Бұл — DOM элементтерінің стилін JavaScript арқылы динамикалық басқару деңгейіне жатады (DOM Style Manipulation / CSSOM).
