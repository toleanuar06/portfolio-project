## 📝 Практикалық сабақ №10 — Бақылау сұрақтары мен жауаптары

1. **input тегінің type="date" және type="color" түрлері веб-бетте қандай интерфейс элементтерін көрсетеді?**  
   *Жауабы:* `type="date"` күнтізбе виджетін (Date picker) көрсетеді, пайдаланушы күн/ай/жылды таңдайды (`YYYY-MM-DD`). `type="color"` түстер палитрасын (Color picker) ашатын батырманы көрсетеді және түстің HEX кодын (мысалы `#ff0000`) қайтарады.

2. **JavaScript арқылы енгізу өрісіндегі мәнді алу үшін қандай қасиет (property) қолданылады?**  
   *Жауабы:* `.value` қасиеті қолданылады (мысалы, `document.getElementById("id").value`).

3. **innerHTML қасиетінің textContent қасиетінен басты айырмашылығы неде?**  
   *Жауабы:* `innerHTML` HTML тегтерін оқиды және өңдеп, DOM құрылымын визуализациялайды. `textContent` кез келген мазмұнды таза мәтін (raw text) ретінде қабылдап, тегтерді орындамай жай мәтін күйінде шығарады.

4. **Шартты операторлар (if...else) бұл тапсырмада не үшін қажет болды?**  
   *Жауабы:* Ойыншы енгізген санды компьютердің жасырын санымен салыстырып, үш бағыт бойынша әрекет ету үшін: 1) дұрыс болса — жеңіс; 2) кіші болса — «Сан үлкенірек»; 3) үлкен болса — «Сан кішірек».

5. **Нәтиженің шекара түсін динамикалық түрде өзгерту (resultBox.style.borderColor = selectedColor) DOM бағдарламалауында қандай деңгейге жатады?**  
   *Жауабы:* Бұл — DOM элементтерінің стилін JavaScript арқылы динамикалық басқару деңгейіне жатады (DOM Style Manipulation / CSSOM).
