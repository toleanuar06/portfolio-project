# Жеке Портфолио және Блог сайты 🚀

Бұл жоба менің кәсіби визиткам және IT саласындағы, сондай-ақ білім беру бағытындағы ойларыммен бөлісетін жеке блогым ретінде құрылды. 

## 📖 Жоба туралы
Сайт заманауи, минималистік стильде (clean design) жасалған. Басты мақсатым — веб-әзірлеудегі дағдыларымды тәжірибе жүзінде көрсету және алға қойған мақсаттарыммен, оқу процесіммен (соның ішінде жасанды интеллектті қолдану және "вайб кодинг") бөлісу.

## ✨ Мүмкіндіктері
- **Басты бет (`index.html`)**: Өзім туралы толық ақпарат, білімім, дағдыларым мен алдағы мақсаттарым.
- **Блог беті (`blog.html`)**: Семантикалық HTML5 тегтеріне негізделген, IT және өзін-өзі дамыту тақырыптарындағы мақалалар жинағы.
- **Стиль және Дизайн (`style.css`)**: Оқуға ыңғайлы, көзді шаршатпайтын түстер палитрасы.

## 🛠 Қолданылған технологиялар
- **HTML5**: Семантикалық тегтерді қатаң сақтау (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`).
- **CSS3**: Flexbox, заманауи типографика және визуалды эффектілер.
- **Типографика**: Google Fonts қызметінен `Inter` қарпі.
