# 🌐 Жеке Портфолио және Блог Веб-сайты

Бұл жоба — HTML5 және заманауи CSS3 (Flexbox) технологияларын қолдана отырып жасалған жеке визитка-портфолио және білім беру блогының веб-парақшасы.

🔗 **GitHub репозиторийі:** [portfolio-project](https://github.com/toleanuar06/portfolio-project)  
🚀 **GitHub Pages сілтемесі:** [toleanuar06.github.io/portfolio-project](https://toleanuar06.github.io/portfolio-project/)

---

## 📌 Жобаның құрылымы мен мазмұны

Жоба негізгі екі беттен және модульдік стильдерден тұрады:

1. **`index.html` (Басты бет / Визитка):**
   - **Header:** Бренд логотипі және негізгі беттерге өту навигациясы (`justify-content: space-between`).
   - **Hero / Card:** Қысқаша ақпарат, мамандық бағыты, аватар және байланысқа апаратын батырмалар.
   - **Skills (Дағдылар):** Негізгі технологиялық стек карточкалары (`flex-wrap: wrap`).
   - **Contacts (Байланыс):** Жеке байланыс мәліметтері мен әлеуметтік желілерге сілтемелер.

2. **`blog.html` (Блог):**
   - Жеке мақсаттар мен оқу жоспарлары туралы жазбалар.
   - Ұстаздық шеберлік пен soft skills дамыту тәжірибелері.

3. **`css/style.css`:**
   - Жобаның барлық беттеріне ортақ стилистика, адаптивті макет және түстер палитрасы.

---

## 🛠️ Қолданылған технологиялар

- **HTML5:** Семантикалық құрылым (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3 (Flexbox):**
  - Элементтерді кеңістікте бөлу (`justify-content: space-between`, `center`).
  - Тігінен және көлденеңінен туралау (`align-items: center`).
  - Көпқатарлы карточкалар торы (`flex-wrap: wrap`, `gap`).
  - Интерактивті эффектілер (`:hover`, `transition`).
- **Адаптивті дизайн (Responsive Web Design):**
  - Мобильді құрылғылар мен кіші экрандарға арналған Media Query (`@media (max-width: 650px)`).
- **Git & GitHub Pages:** Нұсқаларды басқару жүйесі және жобаны желіде жариялау.
