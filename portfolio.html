Бақылау сұрақтары мен жауаптары

№10 практикалық сабақ бойынша бақылау сұрақтарының шешімі

1. input тегінің type="date" және type="color" түрлері веб-бетте қандай интерфейс элементтерін көрсетеді?

Жауабы: type="date" күнтізбе виджетін (Date picker) көрсетеді, ол күн/ай/жылды ыңғайлы таңдап, YYYY-MM-DD мәнін береді. Ал type="color" түстер палитрасын (Color picker) ашатын батырманы береді және таңдалған түстің HEX кодын (мысалы: #ff0000) қайтарады.

2. JavaScript арқылы енгізу өрісіндегі мәнді алу үшін қандай қасиет (property) қолданылады?

Жауабы: .value қасиеті қолданылады (мысалы, document.getElementById("id").value).

3. innerHTML қасиетінің textContent қасиетінен басты айырмашылығы неде?

Жауабы: innerHTML HTML тегтерін өңдеп, DOM элементі ретінде визуализациялайды. Ал textContent тек таза мәтін (raw text) ретінде қабылдап, HTML тегтерін орындамай мәтін күйінде шығарады.

4. Шартты операторлар (if...else) бұл тапсырмада не үшін қажет болды?

Жауабы: «Жасырын санды тап» ойынында енгізілген санды компьютердің жасырын санымен салыстырып, 3 түрлі тармақ бойынша шешім шығару үшін: 1) тең болса — жеңіс; 2) кіші болса — «Сан үлкенірек»; 3) үлкен болса — «Сан кішірек».

5. Нәтиженің шекара түсін динамикалық түрде өзгерту (resultBox.style.borderColor = selectedColor) DOM бағдарламалауында қандай деңгейге жатады?

Жауабы: Бұл — DOM элементтерінің стилін JavaScript арқылы динамикалық басқару деңгейіне жатады (DOM Style Manipulation / CSSOM).
