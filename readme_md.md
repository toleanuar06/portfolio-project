## ✨ Жобаның мүмкіндіктері (Features)

- **Көпбеттік құрылым (Multi-Page):** Басты бет, Блог, Портфолио және Интерактивті күнтізбе бөлек беттерге бөлінген.
- **Толық бейімделгіш (Responsive Design):** Сайт компьютер, планшет және ұялы телефон экрандарында мінсіз жұмыс істейді.
- **Жоғары өнімділік:** Сайт SEO талаптарына сай оңтайландырылған және тез жүктеледі.
- **Интерактивті Блог:** Мақалаларды санаттар (Педагогика, IT, Бағдарламалау) бойынша динамикалық сүзу және модальды терезе арқылы оқу мүмкіндігі.
- **Smart Lesson Planner (Күнтізбе):** JavaScript және LocalStorage арқылы жұмыс істейтін, сабақ жоспарларын сақтауға арналған интерактивті оқу күнтізбесі.

## 🛠 Қолданылған технологиялар (Tech Stack)

- **HTML5** (Семантикалық құрылым)
- **Tailwind CSS** (Стильдер, Grid/Flexbox макеттері, Анимациялар)
- **Vanilla JavaScript** (Модальды терезелер, Блог сүзгісі, Күнтізбе логикасы)
- **FontAwesome** (Векторлық иконкалар)
- **GitHub Pages** (Хостинг)
