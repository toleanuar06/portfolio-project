Практикалық сабақ №10

HTML5 форма элементтері (date, color), JavaScript арқылы батырманың басылу оқиғасын (click) тыңдау, DOM manipulation және «Жасырын санды тап» ойыны.

1. Күн және түс таңдау

Date & Color

Күн таңдау өрісін (<input type="date">) және түс таңдау өрісін (<input type="color">) пайдаланып, мәндерді экранға шығару.

Бақылау сұрақтары мен жауаптары

Сабақты бекітуге және теориялық білімді тексеруге арналған жауаптар

1 input тегінің type="date" және type="color" түрлері веб-бетте қандай интерфейс элементтерін көрсетеді?

Жауабы: type="date" веб-бетте күн, ай, жылды көрнекі таңдауға арналған интерактивті күнтізбе (Date picker) интерфейсін көрсетеді (мәні YYYY-MM-DD форматында). Ал type="color" қолданушыға түстер палитрасын (Color picker) ашатын батырма тәрізді элемент береді және таңдалған түстің он алтылық (HEX) кодын (мысалы, #ff0000) қайтарады.

2 JavaScript арқылы енгізу өрісіндегі мәнді алу үшін қандай қасиет (property) қолданылады?

Жауабы: Енгізу өрістерінен (<input>, <select>, <textarea>) мәнді оқу үшін .value қасиеті қолданылады. Мысалы: document.getElementById("p10-date").value.

3 innerHTML қасиетінің textContent қасиетінен басты айырмашылығы неде?

Жауабы: innerHTML HTML тегтерін өңдейді (парсинг жасайды) және стильдендірілген жаңа элементтерді бетке кірістіруге мүмкіндік береді. Ал textContent кез келген мазмұнды тек қарапайым таза мәтін (raw text) ретінде қабылдайды, HTML тегтерін орындамай мәтін күйінде шығарады (XSS қауіпсіздігі үшін өте маңызды).

4 Шартты операторлар (if...else) бұл тапсырмада не үшін қажет болды?

Жауабы: «Жасырын санды тап» ойынында ойыншы енгізген санды компьютер ойлаған жасырын санмен салыстыру үшін қолданылды: 1) userGuess === secretNumber болса — дұрыс тапты деп хабарлау және шарларды ұшыру; 2) userGuess < secretNumber болса — «Сан үлкенірек» нұсқауын беру; 3) else болса — «Сан кішірек» деп бағыт беру.

5 Нәтиженің шекара түсін динамикалық түрде өзгерту (resultBox.style.borderColor = selectedColor) DOM бағдарламалауында қандай деңгейге жатады?

Жауабы: Бұл DOM (Document Object Model) элементтерінің CSS стилін тікелей JavaScript арқылы динамикалық басқаруға жатады (DOM Style Manipulation / CSSOM). JavaScript элементтің style нысанына қатынасып, оқиға болған сәтте нақты уақыт режимінде элементтің визуалды қасиетін өзгертеді.
